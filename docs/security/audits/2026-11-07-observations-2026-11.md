## Checked, nothing found

- **A01 Broken access control.** Every new route checks a permission of `Permission::MATRIX`: purchase orders
  READ_DOCUMENTS on the class and WRITE_DOCUMENTS on every write; Corregir `PurchasingAccess::mayWrite`; entries
  READ_DOCUMENTS; tax reports and exógena VIEW_BOOKS on the class; exógena concepts GET VIEW_BOOKS, PUT MANAGE_BOOKS;
  geo every signed-in user (401 otherwise, `ContractTest`). Tests prove the refusals (billing 403 on the reports and on
  subdividing an account; accountant and billing write orders).
- **Tenancy (another company).** Proven per endpoint: purchase orders 404 on every id route including convert and PDF
  and a foreign supplier refused (`PurchaseOrderApiTest`); Corregir 404 (`CorrectPurchaseInvoiceApiTest`); entries
  `{items: []}` for another company's document (`JournalEntriesBySourceApiTest`, by design: "gives no entries");
  tax reports, exógena and exógena concepts see only their company (`TaxReportApiTest`, `TaxQueriesTest`,
  `ExogenaApiTest`, `ExogenaConceptsApiTest`); account search and subdivide touch only the company's own rows
  (`AccountSearchApiTest`, `SubdivideAccountApiTest`); `?missing_municipality=1` is company-scoped (`TerceroApiTest`).
  New owned tables implement `CompanyOwned`; `geo_municipality` is read-only reference data with no company column
  (README, data-model decisions).
- **A03 Injection.** New DBAL queries (`DbalTaxQueries`, `DbalExogenaQueries`, `DbalMunicipalities`, `DbalAccountReferences`,
  `DbalJournalQueries::bySource`) bind every value; `LIKE` input is escaped (`%` matches literally: `ContractTest`).
  Enumerated path parts (`{side}`, `{format}`) have route requirements; `source_type` is checked against a list (400).
- **A03 XSS.** React escapes everything rendered; no `dangerouslySetInnerHTML` added. No `|raw` in any template; the
  purchase-order PDF and e-mail print notes and descriptions through Twig's escaping, as the quotation's do.
- **CSV injection.** Every new export goes through `ReportFiles` → `CsvEncoder`, which prefixes a cell starting with
  `= + @ - tab` (a tercero named `=HYPERLINK(…)` does not run).
- **A04 Insecure design / business rules.** Corregir runs the same void (lock, allocations, lock date) in one transaction
  and rolls back entirely on refusal, files included (`CorrectPurchaseInvoiceApiTest`, period locked); a converted
  order cannot be voided or converted twice; the supplier number stays unique among live invoices in the database
  (`purchase_invoice_active_number`) and a race maps to 422 (`DuplicateSupplierInvoiceNumberSubscriberTest`).
- **A08 Files.** Corregir copies attachments through `SupplierFiles::copyAll()` under the company's own storage path with
  new ids; nothing new is uploaded (the existing upload checks stand).
- **E-mail abuse.** The purchase-order e-mail counts against the company's hourly quota (429 `too_many_emails`), like the
  other document e-mails.
- **Secrets.** None in the diff (audit.py: 0).
- **Known gap noted (not a vulnerability):** Corregir writes the copied file bytes before the commit; a commit that fails
  afterwards leaves orphan bytes in the company's storage, unreachable from the API (README, Known gaps).
